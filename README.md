# 내일의 도시 설계실 (future-city-builder)

미래교육원 체험프로그램 3레벨 「나만의 미래도시 설계하기」 수업용 웹 앱 시안입니다.
브라우저에서 바로 실행되며(설치 없음), 태블릿·노트북 터치 조작을 기본으로 합니다.

- `index.html` : 앱 본체 (단일 파일, Three.js r128 사용)
- `models.json` : 3D 모델 묶음 (Kenney 키트, base64)
- `assets/models/` : 원본 GLB 모델, `assets/LICENSE_*` : 에셋 라이선스(CC0)

## 실행
GitHub Pages: 저장소 Settings → Pages → Branch `main` / root 로 켜면
`https://yhg1351-dot.github.io/future-city-builder/` 에서 열립니다.
